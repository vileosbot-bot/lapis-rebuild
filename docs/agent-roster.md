## 账号边界（隔离铁律）

- 写操作只走 bot 号：GitHub vileosbot-bot、谷歌 vileosbot@gmail.com。
- 主号 ViLeo06 只作源头/归档：对智能体一律只读，不写、不合并、不加协作者绕过。
- GPT 登录用户笔记本（Remote Desktop Commander）每次须卫勒逐次确认；笔记本上 ViLeo06 的 GitHub 登录绝不能删、绝不能退。
- 凭据（密码、key、验证码）绝不进仓库、记忆、技能、备份；新增账号、连接器或执行角色时，本表必须同步更新；表里没有的权限，一律视为没有。
- 未明确的连接器权限：标“待核实”，不假定已具备最小权限。

## 自动合并口径（已定版，不在本表里改）

- vileosbot-bot/lapis-rebuild：验收全过、PR 非草稿或先转 ready、无冲突时可自动合并。
- ViLeo06/lapis-rebuild：任何合并须卫勒明确批准。

## 维护

- 每次新增账号、连接器或执行角色时更新本表；权限表过时与实际不一致时，以实际最小权限为准，表须立即修正。
- 本表存在不等于权限已受技术限制；技术限制（分支保护、插件权限）与本表分开核对。
