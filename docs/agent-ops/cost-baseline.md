# Agent Ops 成本基线记录表

版本：P1-4 试点版（2026-11-22）

## 记录口径

- 一轮 = 一次“总管发消息—工人回复”。
- 耗时按任务开始至结束的实际墙钟分钟数记录；暂停区间是否扣除须按 P5 Routine 台账的统一口径，不得对单个任务临时换算法。
- 合并 PR 数只统计已合并 PR；Open PR 不计入合并数。
- 重试次数记录实际重试，不把诊断后缩小范围的新任务混算为原任务重试。
- 超限及原因分类必须有证据；缺失数据写“待总管核对”，不得估算。
- P5 Routine 成本审计日志（自 2026-11-13）是基线来源；本表按月汇总，登记表 `cost_budget.cost_record` 是同一账本的结构化记录，不另建重复账本。

## 12 月校准记录

Chat 并入额度池后，按级别计算试点平均轮数与平均耗时，以平均值 × 1.5 作为预算初值。连续观察一个月：超限率高于约 30% 时评估放宽；低于约 5% 时评估收紧；每月复盘并记录总管批准依据。当前不设置金钱金额。
